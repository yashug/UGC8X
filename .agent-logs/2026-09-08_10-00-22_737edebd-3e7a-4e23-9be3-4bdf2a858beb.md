## The finalised shape

**Free lane costs $0.00 per video and cannot hard-fail.** That's the property I optimised for, since a demo that breaks in front of a grader is worse than one that's slightly less flashy.

```
message → Gemini + generate_ugc_video tool → streamed reply        ~1s
                              └─ tool call → Inngest, 7 durable steps:
   1 fetch    2 extract    3 brief ──► streams into thread
   4 script ──► streams into thread
   5 assets (voice ∥ hook clip ∥ screenshots)
   6 render  → GitHub Actions → Remotion → R2
   7 deliver → URL posted to the thread
```

Three things I'd point at specifically:

**Tool-use replaces the classifier.** One Gemini call decides chat-vs-render. "hi" gets a greeting because the model didn't call the tool — not because a separate router said so. One less system to drift.

**Steps 3–4 fill the wait.** They finish in ~10s while the render takes another two minutes. So the user reads the actual product brief and the actual 5-scene script while it works — which incidentally proves the pipeline is really reading their site.

**Every capability degrades alone.** No `og:image` → typographic brand cards from the extracted palette. Pexels finds nothing → open on a text card. TTS down → captions + music, and the bot *says* it skipped the voiceover. Full matrix is in §7.

On your GitHub Actions choice — it's genuinely free with no card, and the cost is ~40–90s of runner boot per render plus no frame-level progress. I've planned the Chrome-shell cache to blunt the first and coarse stage updates for the second. Expect ~2–3 min end-to-end.
